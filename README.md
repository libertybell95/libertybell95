# 👋 Hey there, I'm Josh

I'm a software and hardware engineer working at the intersection of IoT, automation, and scalable web systems. I build tools that connect machines, sensors, and people — from embedded firmware and device communication layers to full-stack web applications and cloud services.

My focus areas include:
- Embedded systems & low-power IoT devices  
- Industrial automation and telemetry  
- Scalable APIs and data pipelines  
- Web interfaces for control and visualization  

I care deeply about **reliability**, **maintainability**, and **clarity in design**. Years of working with both hardware and software have shaped how I think about systems — everything’s a signal chain, from physical input to human insight.

## 🧱 Principles I Work By

1. **Design for failure** — assume power loss, packet loss, and human error.  
2. **Measure before optimizing** — premature abstraction kills clarity.  
3. **Security through simplicity** — the fewest moving parts win.  
4. **Documentation is a first-class artifact**, not an afterthought.
